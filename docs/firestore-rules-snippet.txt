용돈 기록장 보안 규칙 (Firestore)

이 파일은 배포 대상이 아니에요. Firebase 콘솔 > Firestore Database > 규칙 에서
기존 규칙(마음조각 앱 규칙)은 그대로 두고, 아래 블록을 `match /databases/{database}/documents { ... }` 안에 한 줄 띄워 추가해 주세요.
(터미널에서 `firebase deploy --only firestore:rules`를 쓰면 기존 규칙이 덮어써져요. 쓰지 마세요.)

    // 용돈 기록장: 로그인한 본인만 자기 기록을 읽고 써요.
    match /yongdonBooks/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
