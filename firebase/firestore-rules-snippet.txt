용돈 기록장 보안 규칙 (Firestore)

Firebase 콘솔 > Firestore Database > 규칙 에 아래 블록이 들어 있어야 해요.
기존 규칙(마음조각, 퓰리처, 바나나 앱 등)은 그대로 두고 `match /databases/{database}/documents { ... }` 안에 추가해요.
(터미널의 `firebase deploy --only firestore:rules`는 기존 규칙을 덮어쓰니 쓰지 마세요.)

    // 용돈 기록장: 로그인한 본인만 자기 기록을 읽고 써요.
    match /yongdonBooks/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
